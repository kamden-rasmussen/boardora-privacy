Boardora Privacy Policy

Last updated: September 29, 2026

Boardora is an unofficial mobile client for Planka, a project board application. Boardora is not affiliated with or endorsed by Planka.

What Boardora stores on your device

Boardora stores the following in your device's secure, encrypted storage (iOS Keychain):

  • Your login session token or API key for the Planka server you connect to
  • The server URL you enter
  • Your app lock (Face ID / Touch ID) preference, if enabled

This data never leaves your device except to authenticate directly with the Planka server URL you provide.

What Boardora does not do

  • Boardora does not run its own servers or backend
  • Boardora does not collect analytics, usage data, or crash reports
  • Boardora does not contain advertising or third-party trackers
  • Boardora does not share any data with the app developer or any third party

Your Planka server

When you sign in, Boardora communicates directly with the Planka server you specify (your own self-hosted instance, or one operated by a third party of your choosing). That server's own privacy practices govern any data you send it — boards, cards, comments, attachments, and account information. Boardora has no visibility into or control over that server.

Biometric authentication

If you enable Face ID / Touch ID app lock, authentication is handled entirely by iOS on-device. Boardora never receives or stores biometric data itself.

Contact

Questions about this policy can be sent via the Boardora GitHub repository.
